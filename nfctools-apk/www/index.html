About

      
A tiny NFC read/write tool. Uses the Web NFC API, so it works on Android Chrome (and any other browser that supports it). iOS Safari does not currently support Web NFC.

      
Privacy

      
Everything runs in your browser. No tag data is sent anywhere. History is stored in localStorage on this device.

      
Limits

      
    
        
  • Web NFC can read and write NDEF-formatted tags.
    • 
        
  • Tags smaller than ~168 bytes can't hold complex records.
    • 
        
  • You can't permanently lock tags from a browser — that needs a native app.
    • 
        
  • Some tag types (Mifare Classic without NDEF, ISO 14443-4 cards) are read-only or unsupported.
